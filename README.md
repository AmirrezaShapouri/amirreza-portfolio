# Amirreza Shapouri — Portfolio

A bilingual personal portfolio website for Amirreza Shapouri, built with Astro and TypeScript.

## Planned stack

- Astro
- TypeScript
- Tailwind CSS
- Markdown / MDX content
- Persian (RTL) and English (LTR)
- Vercel deployment

## Project status

Initial project setup is in progress. The site will present selected projects, professional background, services, technical writing, and contact information.
